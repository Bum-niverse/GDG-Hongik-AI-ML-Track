이번 주차에서는 정답이 없는 데이터를 비슷한 특징끼리 나누는 K-평균(K-means) 군집 알고리즘을 실습하였다.

이전 주차까지는 생선이나 와인 데이터처럼 정답이 주어진 상태에서 분류 또는 회귀 모델을 학습하였다. 하지만 이번 주차에서는 과일 사진과 Iris 데이터를 사용하여 정답을 모델에 알려주지 않고, 데이터 사이의 거리와 군집 중심을 기준으로 그룹을 나누었다.

## 📌2. K-평균 군집 알고리즘

K-평균은 비슷한 데이터를 K개의 군집으로 나누는 비지도 학습(Unsupervised Learning) 알고리즘이다. 지도 학습과 달리 정답인 타깃 데이터가 없기 때문에, 각 샘플과 군집 중심 사이의 거리를 이용한다.

K-평균의 과정은 다음과 같이 이해하였다.

1. 먼저 K개의 군집 중심을 정한다.
2. 각 데이터를 가장 가까운 군집 중심에 배정한다.
3. 같은 군집에 배정된 데이터의 평균으로 군집 중심을 다시 계산한다.
4. 군집의 변화가 거의 없을 때까지 배정과 중심 계산을 반복한다.

```python
from sklearn.cluster import KMeans

km = KMeans(n_clusters=3, random_state=42, n_init=10)
km.fit(fruits_2d)
```

`n_clusters`는 만들 군집의 개수이고, `labels_`에는 각 데이터가 속한 군집 번호가 저장된다. `cluster_centers_`를 사용하면 K-평균이 찾은 각 군집의 중심도 확인할 수 있다.

## 📌3. 과일 사진 데이터

과일 사진 데이터는 300장의 흑백 이미지로 이루어져 있고, 각 사진의 크기는 100×100이다.

```python
fruits = np.load("fruits_300.npy")
print(fruits.shape)
```

출력되는 크기는 `(300, 100, 100)`이다. K-평균에 입력하기 위해 각 사진을 10,000개의 픽셀값을 가진 1차원 배열로 변환하였다.

```python
fruits_2d = fruits.reshape(-1, 100 * 100)
```

처음에는 사진 한 장이 2차원인데 왜 펼쳐야 하는지 헷갈렸다. scikit-learn의 입력은 일반적으로 `(샘플 수, 특성 수)` 형태여야 하므로, 사진 한 장을 하나의 샘플로 보고 각 픽셀을 특성으로 사용한 것이라고 이해하였다.

과일별 평균 이미지를 구하고 각 사진과 평균 이미지 사이의 절댓값 차이를 계산하면, 평균 이미지와 비슷한 과일을 찾을 수 있었다. 단순한 픽셀 평균만으로도 과일 종류마다 어느 정도 다른 분포가 나타나는 점이 흥미로웠다.

## 📌4. Inertia와 Elbow Method

inertia는 각 데이터와 자신이 속한 군집 중심 사이 거리의 제곱합이다. 군집 안의 데이터가 중심에 가까울수록 inertia가 작아진다.

```python
inertia = []

for k in range(1, 11):
    km = KMeans(n_clusters=k, random_state=42, n_init=10)
    km.fit(iris_data)
    inertia.append(km.inertia_)
```

K값을 늘리면 군집이 더 잘게 나뉘기 때문에 inertia는 계속 작아진다. 따라서 가장 작은 inertia만 보고 K를 선택하면 안 된다. 그래프에서 inertia의 감소 폭이 급격히 완만해지는 지점을 찾는 방법이 Elbow Method이다.

Iris 데이터의 그래프에서는 K가 3인 지점이 팔꿈치처럼 꺾이는 것으로 보여 `best_k = 3`으로 선택하였다. 실제 Iris 데이터에 품종이 3개 있다는 사실과도 일치하지만, K-평균 학습 과정에는 품종 정답을 사용하지 않았다.

## 📌5. Iris 데이터 군집화

과제에서는 Iris 데이터의 네 특성 중 꽃잎 길이와 꽃잎 너비만 선택하였다.

```python
iris_data = data[:, [2, 3]]
```

두 특성만 사용하면 결과를 2차원 산점도로 표현할 수 있다. K를 3으로 정한 후 모델을 학습하고 `np.unique()`로 군집별 데이터 개수를 확인하였다.

```python
km = KMeans(n_clusters=3, random_state=42, n_init=10)
km.fit(iris_data)

labels, counts = np.unique(km.labels_, return_counts=True)
```

산점도에서는 같은 군집을 같은 색으로 표시하고, 군집 중심은 빨간색 X로 표시하였다. 한 군집은 비교적 명확히 떨어져 있었지만 나머지 두 군집은 경계 부분에서 서로 가까운 데이터가 있었다. K-평균은 실제 품종 이름을 맞추는 분류 모델이 아니라 거리 기준으로 데이터를 묶는 모델이므로, 군집 번호와 실제 품종 번호가 반드시 같은 순서일 필요는 없다는 점도 알게 되었다.

## 📌6. PCA

과일 사진은 한 장당 10,000개의 픽셀 특성을 가지므로 특성 수가 매우 많다. PCA(Principal Component Analysis)는 데이터의 분산을 최대한 보존하면서 더 적은 수의 주성분으로 특성을 줄이는 차원 축소 방법이다.

```python
from sklearn.decomposition import PCA

pca = PCA(n_components=50)
fruits_pca = pca.fit_transform(fruits_2d)
```

10,000개의 특성을 50개로 줄이면 저장 공간과 계산량을 줄일 수 있다. 이후 `inverse_transform()`으로 다시 원래 차원에 가깝게 복원할 수 있지만, 축소 과정에서 일부 정보가 사라지기 때문에 원본과 완전히 같지는 않다.

## 📌7. 느낀점

이번 주차에서는 처음으로 정답 데이터 없이 모델이 스스로 비슷한 데이터를 묶는 과정을 다루었다. 이전까지는 훈련 데이터와 타깃 데이터를 함께 넣는 것이 익숙했기 때문에 `fit()`에 입력 데이터만 전달하는 방식이 처음에는 낯설었다. 하지만 군집 중심을 정하고, 가까운 데이터를 배정한 다음, 다시 중심을 갱신하는 과정을 생각하니 K-평균이 어떤 원리로 동작하는지 이해할 수 있었다.

특히 Elbow Method가 기억에 남았다. K가 커질수록 inertia가 무조건 감소하기 때문에 단순히 수치가 가장 작은 경우를 고르는 것이 아니라, 감소 폭이 완만해지는 지점을 찾아야 했다. 그래프를 통해 K를 선택하는 과정에는 어느 정도 해석이 필요하다는 것도 알게 되었다.

또한 Iris 결과를 시각화하면서 군집과 분류의 차이를 더 분명하게 이해하였다. 군집 번호는 실제 품종 이름이 아니며, 정답 없이 거리만으로 나눈 결과이다. 데이터가 겹치는 부분에서는 실제 품종과 완전히 같게 나뉘지 않을 수도 있다. 이번 실습을 통해 모델의 결과를 숫자로만 확인하지 않고 그래프와 군집 중심을 함께 살펴보는 것이 중요하다고 느꼈다.
