# GDG-Hongik-AI-ML-Track

Weekly study notes and Jupyter notebooks from the 2026 first-semester machine learning study at GDG on Campus Hongik University.

## Contents

- `week1`–`week6`: weekly exercises, experiments, and learning notes
- Topics progress from core machine learning concepts to hands-on model implementation and evaluation

## How to Use

Open each weekly directory and run its notebook in Jupyter Notebook, JupyterLab, or Google Colab. Install the libraries imported by the selected notebook before running all cells.

## Purpose

This repository documents my learning process as an AI/ML track participant and preserves reproducible study artifacts for later review.
